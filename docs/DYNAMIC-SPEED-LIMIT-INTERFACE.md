# 面板管理动态限速接口（v1，本地候选，未发布）

节点按 `(面板节点 tag, 用户认证代际)` 隔离统计；同一用户在同一节点的 TCP/UDP、多个连接及上传下载共享策略。不是套餐耗尽降速，也不是跨节点总量限制。

## 用户接口

沿用 `GET /api/v1/server/UniProxy/user` 的现有鉴权。新节点发送 `X-V2bX-Dynamic-Speed-Limit: 1`。面板只向声明支持的节点返回用户对象的可选 `dynamic_speed_limit` 字段。JSON 与 MessagePack 字段与单位完全一致。

```json
{"version":1,"revision":12,"enabled":true,"window_seconds":60,"threshold_bytes":1000000000,"speed_mbps":20,"duration_seconds":300}
```

面板计算套餐继承/用户覆盖后的最终规则；所有有效策略变化递增 revision（包括关闭）。显式关闭发送 `{"version":1,"revision":13,"enabled":false}`。更新规则必须改变用户接口 ETag，并按能力区分缓存响应；不能向旧节点误发新版缓存。

约束：version=1；revision 为正 int64；启用时 window_seconds=1..3600，threshold_bytes=1..2^60，speed_mbps=1..1000000（十进制 Mbps，除 8 得字节每秒），duration_seconds=1..86400。禁止用 0 Mbps 表示封禁。参数非法或未来版本只拒绝该策略，不能撤销用户。日志不得包含响应正文、凭据或 UUID。

完整 200 响应中省略/null 表示移除策略；304 表示全部保持；网络/解析失败保持上次有效状态。禁止把增量用户列表作为完整列表返回。未知/非法策略保留该用户最后有效规则，新用户无有效规则时保持原有固定限速。

revision 低于已接受值，或相同 revision 却内容不同，均不覆盖已有策略。相同规则反复同步不清空窗口、不延长限速。省略/null 为兼容旧面板的明确移除操作；恢复发送时应使用更高 revision。

## 执行语义

原始计费观察点的上传+下载字节，不乘倍率，不含可靠批次重放。1 秒粒度滑动窗口与检查，属于近似时间窗口；允许检查/调度期间超量，不是硬流量配额。达到阈值即临时限速；限速期间不延长处罚；到期清空窗口开始新统计周期。现有固定上限与临时上限取最小正值。

关闭解除临时策略但保留固定限速、认证和设备信息。窗口/阈值变化重建观察窗口，已触发截止时间不延长。面板失联继续最后有效规则，已触发限制仍按时到期。撤销授权优先。进程重启清空窗口及临时限速，重新拉取后开始统计；v1 不落盘这些状态。订阅、计费接口、可靠队列格式均不变。

面板不必新增实时流量 RPC；数据库/管理 UI 的实现由面板维护 agent 决定。当前仅开发 V2bX 端，两机联调必须在面板配套完成后进行。
