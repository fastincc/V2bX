# Independent Hysteria2 connection admission

Authentication now returns a separate opaque runtime handle for each accepted QUIC connection. The handle points to the existing user accounting generation. Device admission happens before authentication succeeds; subsequent request checks can terminally reject only that connection. A legitimate request on another connection cannot clear its rejection. User revocation still invalidates all handles belonging to the old generation, including after the credential is re-added.

Traffic continues to accumulate by the original accounting generation and UID, with unchanged upload/download direction and reliable journal format. Disconnect removes the handle, not its counter. Traced TCP streams retain their handle until their final callback finishes; repeated disconnect/untrace is safe. Source IP normalization and the existing device admission/snapshot policy remain in the limiter. This patch does not change independent Hy2's native bandwidth/congestion configuration or add per-packet limit checks.

No new configuration, subscription, panel API or database migration is required. Only the independent hysteria2 core changes. New behavior: an over-device-limit connection fails authentication instead of sharing a denial flag with already authenticated connections. Session state uses memory proportional to active connections/streams, and the existing traffic lock covers one additional session lookup; there is no extra per-packet mutex or timer.

Tests: `TestHy2Session*`, existing `TestHysteriaQUICNodeIsolation`, `TestRevokedTailGenerationAndPersistence`, and checkpoint/privacy tests. The real device isolation test requires a second assigned local IPv4 source; the server and targets remain bound to loopback. It requires an authentication error, never treating socket setup or transport failure as a valid denial. `HY2_PROFILE_DURATION=5s HY2_PROFILE_PARALLEL=8` enables the real loopback TCP/QUIC throughput, CPU/RSS and bidirectional accounting profile. WAN behavior and long-term memory remain separate acceptance scopes.
